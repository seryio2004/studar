• Serial presence detect (SPD): Pequeña memoria de 256 Bytes que
  describe el módulo de memoria.
• Standardized way to automatically access information about
  a computer memory module. When an ordinary modern computer
  is turned on, it starts by doing a power-onself-test (POST). Since
  about the mid-1990s, this process includes automatically
  configuring the hardware currently present. SPD is a memory
  hardware feature that makes it possible for the computer to know
  what memory is present, and what timings to use to access the
  memory.
• Some computers adapt to hardware changes completely
  automatically. In most cases, there is a special optional procedure
  for accessing BIOS parameters, to view and potentially make
  changes in settings. It may be possible to control how the computer
  uses the memory SPD data—to choose which settings to use, to
  selectively modify the memory timings, or possibly to completely
  over-ride the SPD data

• Single Channel: Todos los módulos de memoria
  intercambian información a través de un único canal,
  64 bits, para ello sólo es necesario colocar los
  módulos DIMM en los conectores de ese canal.
• Dual Channel: Existen 2 canales de memoria, 64 + 64
  bits, cada canal puede tener varios conectores
  DIMM. Se reparten los módulos de memoria entre
  los 2 canales. Pueden intercambiarse datos a través
  de 2 canales simultáneamente.

• To achieve dual channel mode, following conditions must be met:
   – Matched DIMM configuration in each channel
   – Same density (128 MB, 256 MB, 512 MB, etc.)
   – Matched in both Channel A and Channel B memory channels
   – Populate symmetrical memory slots (Slot 0 or Slot 1)
   – Configurations that do not match the above conditions revert to Single
     Channel mode.
• The following conditions do not need to be met:
   – Same brand
   – Same timing specifications
   – Same DDR speed
   – Memory channel speed is decided by the slowest DIMM module
     populated in the system.

                        Channel
• Ganged Mode (modo agrupado)
  – Los dos canales forman un canal lógico de 128 bits
  – El controlador accede a ambos módulos al mismo tiempo como
    si fueran uno solo.
  – Ideal para cargas de trabajo de un solo hilo que requieren
    acceso ancho y secuencial a memoria.
  – Más ancho de banda, pero menos concurrencia.
• Unganged Mode (modo desagrupado)
  – Los dos canales son independientes, 64 bits cada uno.
  – Permite accesos independientes y concurrentes desde múltiples
    hilos o núcleos del procesador.
  – Ideal para cargas multihilo y sistemas multitarea.
  – Puede mejorar el rendimiento general en escenarios modernos.
